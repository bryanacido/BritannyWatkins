# Emma - Brittany Watkins Web Pages

This project contains landing pages for Brittany Watkins' "The Tapping Circle" program.

## Project Structure

```
Emma/
├── Sales Page/
│   ├── index.html          # Main sales page
│   ├── assets/             # Images, fonts, and other media
│   └── Brittany Watkins_Sales Page.pdf
│
├── Offer Page/
│   ├── index.html          # Exclusive offer/checkout page
│   ├── assets/             # Images, fonts, and other media
│   └── Brittany Watkins_Offer page.pdf
│
└── README.md
```

## Pages

### Sales Page
The main landing page for "The Tapping Circle" program. Features program information, testimonials, and call-to-action sections.

### Offer Page
An exclusive offer page with checkout flow for the program purchase.

## Tech Stack

- HTML5
- CSS3 (inline styles)
- Google Fonts (Playfair Display, Open Sans, Inter)

## Usage

Open `index.html` in either folder directly in a web browser to view the pages.
